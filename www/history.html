Timeline, people, context

History and context

Joey lived for roughly a year, from an internal 0.1 in March 2007 to a quiet stop in 2008. This page puts the code's own dates next to what Mozilla and the press said at the time.

Timeline

  • December 2004Mozilla hires Doug Turner to work full-time on mobile, first on Minimo, the embedded Gecko browser.
  • March 2007Joey 0.1 is marked complete on the Mozilla Labs roadmap. The seed rows in joey.sql (content source types, carriers, the "Not Sure" phone) are dated 2007-03-18, and the privacy policy document was last printed 2007-03-23.
  • Mid-May 2007Public launch under Mozilla Labs. On May 26 RCR Wireless reports that Joey "launched two weeks ago" and is "still in the testing stage", with Turner estimating "a few thousand people" using it. A Java phone app and RSS support are described as planned.
  • June 29, 2007The first iPhone goes on sale. It has a real browser and no third-party apps. The code soon grows an iphone layout built on iUI.
  • August 13, 2007Mozilla Labs posts a Joey tutorial video, by then introducing it as something "we introduced back in May".
  • September 18, 2007The Subversion history preserved in this repository begins, with Marcio Galli's UI polish of the login page. The Java ME client is already present; Michael Koch's commits that week switch it to the newer J2ME Polish and add the server URL property. Doug Turner tags the J2ME build as 0.3.
  • October 2007Wil Clouser adds Google Analytics (bug 399038). Galli builds the 0.3.x first-run "Welcome to Joey!" page with its guided tour, and the DOM "page talk" handshake between the page and the extension. A login bug (399929) is patched.
  • November 27, 2007Turner announces that Minimo is no longer supported. Two days later the last J2ME Polish import lands in Joey.
  • December 16, 2007Last commit on the trunk (svn.mozilla.org/labs/joey/trunk@8907). The extension's manifest still says 0.3.0.0.
  • 2008Mozilla's mobile work consolidates on Fennec, the project that became Firefox for Android. The App Store opens in July. Joey is not updated again; the Labs wiki records "no plans to productize Joey".
  • February 2009InfoWorld, writing about Fennec, notes that Joey "fizzled after about a year and is no longer supported".
  • January 4, 2014Doug Turner publishes the tree on GitHub with a one-line README: "A project from pre-iphone days."

The people

Doug Turner

Creator and lead. Then Mozilla's lead engineer for mobile technology, previously the lead on Minimo. Author of the extension's XUL and JavaScript, the mocoJoey XPCOM component, the server scripts and joeyd.py, and the microsummary and feed-watcher features. Later led the Fennec and Firefox OS platform work.

Marcio Galli

UI and front end. The green "Project Joey" theme, the AJAX uploads page and its inline media players, the status-bar upload manager with progress meters, the page-area highlighter, the first-run welcome page and guided tour, and the pt-BR locale. The most active committer in the preserved history.

Michael Koch

Java ME client. An engineer at Enough Software, makers of J2ME Polish, which is why the MIDlet is a showcase of Polish's CSS-styled LCDUI, device database and per-handset builds. Added the German locale.

Wil Clouser

Mozilla web developer (addons.mozilla.org). Server-side CakePHP work, the Kubla CMS-derived layouts and elements, and Google Analytics. Several model and element files carry his original-author header.

The 2007 context

The carrier deck. Most phones reached the Web through a carrier portal and a WAP browser. RCR Wireless framed Joey as letting users "create their own mobile deck", which is exactly what the uploads list was: a personal portal of things you chose, rendered simply enough for any phone.

Java ME was the app platform. There was no App Store. A downloadable app meant a MIDlet, packaged per device because every handset's Java differed. Joey's registration form asked for your phone model and carrier so the server could pick the right JAR and e-mail its download link to your phone as an SMS through the carrier's e-mail gateway. The operators table of 42 carriers and their gateway domains is a fossil of that world.

Mozilla had no mobile browser. Minimo had proven that Gecko on a 2005 phone was too slow and too big. Joey was a way to be useful on phones without solving that problem, by moving the rendering work to Firefox on the desktop and to the server. Fennec, started as Joey wound down, took the opposite bet: wait for phones that could run Gecko.

The iPhone changed the question. Within weeks of launch the server had an iPhone layout, but the honest state of that code, with debug print_r dumps where the audio and video players should be, shows the problem: a phone with a real browser and no Flash, no AMR and no 3GP support did not want Joey's transcoded output. It wanted the original Web.
