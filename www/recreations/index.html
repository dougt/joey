Appendix

Reconstructed server pages

Static renderings of the Joey server's CakePHP views, built from the original templates, stylesheets and images in server/app. The 2007 PHP application cannot be run on a modern stack, so each page below is the markup the .thtml view would have emitted, with the PHP evaluated by hand and sample data filled in.

These are reconstructions, not captures of the live joey.labs.mozilla.com site. The CSS, banner art, icons and iUI/XHTML-MP stylesheets are the originals; only the sample uploads are invented. Firefox 2's -moz-border-radius corners are shimmed with the unprefixed property.

Desktop web (default layout)

  • Login / landing page — users/login.thtml
  • Uploads list, logged in — uploads/index.thtml
  • Register — users/register.thtml
  • Get the software — users/get_software.thtml

First-run page (joeyclient layout)

  • Welcome to Joey! with the guided tour live — version/index.thtml + release_notes/0.3.0.0

Phone browsers

  • iPhone view (iUI) — uploads/iphone_index.thtml, best at 320px wide
  • XHTML Mobile Profile view — uploads/mp_index.thtml, best at 240px wide

Rebuilding

cd www/recreations
node build-web.js   # regenerates web-*.html from the templates in the script
node shoot-web.js   # screenshots them into ../img/screenshots/
